# Destruction intentions 1.0

`npm run generate:des1` selects distinct physical chains and writes a catalogue, full native witnesses and a report. `npm run test:des1` replays both witnesses for every accepted level and checks premature release, branch ownership, portal pairing and bridge access.

The planner runs before geometry. Its operators are source release (slope gate or hinged trapdoor), collection, break/tilt release, directed portal transport, magnetic hold/knockout and final delivery. The composed mode independently chooses transfer topology, number of sources/receiver layers and transport. A numeric seed builds deterministic standard-size bodies and native curved ribbons. Structural signatures collapse mirrors and seed changes; release operators and directed stage edges distinguish compositions.

`IntentObjectives` observes native poses and portal events. Each gray cargo body has a stage passport. Capture needs a dwell interval, a merge needs quota from every source, and parallel delivery requires the packet's own receiver. The observer never applies force, moves bodies or activates objects. Clearing orange pegs alone cannot win. Opening a cup before capture fails explicitly.

The native evaluator uses the same level normalization and `Game.update` as the player, with injected rendering/input and a virtual clock. Native trajectory previews only propose angles; complete ball/debris dynamics decide acceptance. It checks idle stability, capture-before-release, a complete route, exact replay and another route at an earlier start with different randomness. The proof lists source fingerprints and every measured transfer. Identical angles need not remain successful at different timings.

The publication catalogue has 14 distinct compositions. The browser can generate additional verified variants in a cancellable module worker. A ready handshake avoids dropping the first request while dynamically imported native modules initialize. Blob worker entry permits CORS module imports from the pinned jsDelivr commit. Fresh URLs preserve seed/mode; arbitrary direct seed URLs bypass selection and can be rejected by geometry or gameplay.

Main, `/gen`, `/des`, `/des1`, share players and editors import common native physics chunks from the same jsDelivr commit. Vercel builds only tiny launchers. The research source/export files stay untouched; the earlier destruction recipe generator remains available at `/des`.
