# Des4 — destruction_fields 0.1

This generator constructs contours, recursive skeletons, support graphs and travel fields. It deliberately replaces Des3's universal source–receiver–catcher layers. `generateLevel({seed, domain:'auto'})` is synchronous deterministic JavaScript and makes no model/network calls. `domain` chooses a shape/interaction law, not a saved coordinate list; the compiler computes fresh profiles, sizes, attachment points and spatial embeddings. Browser-compatible compilation is retained, while `/des4` publishes an offline native-verified catalog.

Thirteen domains currently cover enclosed rotating vessels, cubic fish silhouettes, bearing frames, branched fruit trees, harmonic petals, oriented portal remapping, folded channels, unequal orbital packing, suspended shapes, oblique reactive panels, magnetic basins, spirals and analytic contour growth with surface attachments. The vocabulary remains coded and bounded. Harmonic recipes and recursive/packing rules produce new formations inside it; they do not discover new game mechanics or infer human intentions automatically.

Ordinary orange clearing, 12 normal balls, bucket and existing native peg types are retained. Ball radius is 8.5. Circle sizes vary mostly from 8.5 to 15 px; warped brick paths have real joined cubic geometry and variable cross-sections. Individual circle scale is now consistent in the native destruction solver too. No stages, sequence objectives, early-release defeat or permanent cargo obstacles exist.

The iteration ledger records direct image review and native results. Thirty to thirty-nine previews were inspected in successive revisions; native winning-route images were compared with them. Selection includes first shot access, clearing rhythm, 12-second idle stability, real hit-trigger displacement, portal usage, fixed-policy field ablation and support collapse. A native route is evidence of playability, not a measure of human enjoyment. Final images require direct review after machine selection.

Candidate reuse requires the same evaluator/runtime fingerprint and identical generated geometry. Added forms do not invalidate physically identical old candidates, while changed forms must be re-evaluated. Full winning replay creates the exported frames. `robustness.mjs` searches again using a different collision stream/start and samples the actual production animator through continuous and hit-trigger cycles. Sampled envelopes are not continuous collision proofs.

Run:

```sh
node generators/destruction4/preview.mjs
python3 generators/destruction4/render.py 07
node generators/destruction4/build-catalog.mjs
node generators/destruction4/robustness.mjs
python3 generators/destruction4/render.py 07 --catalog
node generators/destruction4/build-report.mjs
npm run test:des4
```

Prior campaigns and the research checkout are retained. Public player uses the same production art and unlocked map as Alea; it does not run a model or native solver in the phone UI. Future worker generation can reuse the compiler, but an arbitrary seed is not automatically certified.
